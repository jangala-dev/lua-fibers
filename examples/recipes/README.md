# Facility recipes

These modules are tested examples of composing the supported public resource toolkit. They are deliberately outside `src/` and are not part of the installed version 1 API.

- `rate_limiter.lua` — Machine transitions and transactional time;
- `countdown_latch.lua` — a count-to-zero state machine;
- `priority_queue.lua` — Index and Counter composition;
- `resource_pool.lua` — Index, Keyed, ClaimSet, Cell and effects.
